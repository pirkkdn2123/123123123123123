# 기사의 서약 — GitHub Pages

## 올리는 방법
1. GitHub 저장소에서 기존 `index.html`을 이 파일로 교체합니다.
2. `Commit changes`를 누릅니다.
3. GitHub Pages가 재배포되면 기존 URL을 새로고침합니다.

## 이번 수정
- 카메라 기준 좌우 조작 수정: 화면 왼쪽/오른쪽과 이동이 일치합니다.
- 적들이 공격 전에 몸을 젖혔다가 앞으로 파고드는 공격 모션을 추가했습니다.
- 적에게 맞으면 기사가 휘청이고 뒤로 밀리는 피격 모션을 추가했습니다.
- 체력이 0이 되면 같은 스테이지를 자동으로 처음부터 다시 시작하며, 적·유물·관문이 재생성되고 적 체력은 모두 가득 찹니다.
- 모바일 달리기 토글 버튼을 추가했습니다. PC에서는 `Ctrl`을 누르는 동안 달리고, `R`로 달리기를 켜고 끌 수 있습니다.
- 이동 경계 밖에 스테이지 테마에 맞는 산맥, 숲, 마을, 동굴, 설산, 화산, 성채 등의 배경 실루엣을 추가했습니다. 이동 가능 범위는 그대로 제한되어 있습니다.

## 조작
- 모바일: 왼쪽 조이스틱 이동, 달리기 ON/OFF, 구르기, 검 휘두르기
- PC: WASD/방향키 이동, Ctrl 달리기(누르는 동안), R 달리기 전환, Shift 구르기, Space/Enter 공격

3D 렌더링에는 CDN의 Three.js 모듈을 사용합니다. 실제 휴대폰에서 확인한 뒤 실사용 NFC 카드에 배포하세요.
